# 11. 웰패밀리 디자인 시스템 (Design System)

공개 페이지(`prototype/index.html`)의 디자인 규칙입니다. 새 화면이나 기능을 만들 때 이 문서를 먼저 봅니다.

> 적용 범위는 공개 페이지입니다. `admin.html`(로컬 전용)과 `widget.html`(비공개)은 아직 이전 스타일을 씁니다.

## 1. 디자인 원칙

1. **쉽게 읽히는 것이 먼저입니다.** 어르신도 읽을 수 있어야 합니다. 글자는 14px 미만으로 쓰지 않습니다.
2. **아는 만큼만 말합니다.** 계산하지 않은 금액이나 확인하지 않은 자격을 보여 주지 않습니다.
3. **빨리 찾고 떠나는 화면입니다.** 탭 없이 한 화면에서 끝냅니다. 불필요한 단계를 만들지 않습니다.
4. **차분하고 따뜻하게 만듭니다.** 청록색과 따뜻한 회색을 씁니다. 정부 사이트처럼 보이지 않게 합니다.

## 2. 파일 구조

| 파일 | 역할 |
| :--- | :--- |
| `prototype/index.html` | 화면 구조, 아이콘 모음, 카드 템플릿 |
| `prototype/styles.css` | 토큰과 모든 컴포넌트 스타일 |
| `prototype/app.js` | 데이터, 필터, 화면 상태 |

외부 CDN을 쓰지 않습니다. 글꼴은 기기에 있는 한글 글꼴을 씁니다. 아이콘은 [Lucide](https://lucide.dev)(ISC 라이선스)를 페이지 안에 넣었습니다.

## 3. 토큰

토큰은 세 단계입니다. 컴포넌트에서는 원시 값을 직접 쓰지 않습니다.

| 단계 | 뜻 | 예 |
| :--- | :--- | :--- |
| 기준 (Reference) | 실제 값 | `--teal-700`, `--space-4` |
| 의미 (Semantic) | 쓰임새 | `--color-action`, `--color-text-secondary` |
| 컴포넌트 (Component) | 부품 전용 값 | `--control-height`, `--card-padding` |

### 색

| 토큰 | 쓰임 | 대비 |
| :--- | :--- | :--- |
| `--color-text-primary` | 본문 | 16.7:1 |
| `--color-text-secondary` | 보조 글자 | 6.9:1 이상 |
| `--color-text-brand` | 금액, 강조 | 7.2:1 이상 |
| `--color-action` | 주요 버튼, 선택된 필터 | 5.4:1 |
| `--color-text-caution` | 주의 글자 (`확인 필요`, 안내 띠) | 8.1:1 이상 |
| `--color-text-danger` | 오류 | 7.6:1 |
| `--color-border-control` | 입력칸 테두리 | 4.8:1 |
| `--color-focus` | 키보드 초점 표시 | 5.2:1 이상 |

정보를 색으로만 전달하지 않습니다. 선택 상태는 채움으로, `확인 필요`는 글자와 아이콘으로 함께 보여 줍니다.

### 글자와 크기

- **글자 크기:** `--text-sm`(14px)부터 `--text-2xl`(24px)까지, 제목은 `--text-display`를 씁니다.
- **한글 줄바꿈:** `word-break: keep-all`로 단어 중간에서 끊기지 않게 합니다.
- **숫자:** 금액과 건수는 `tabular-nums`를 씁니다.
- **간격:** 4px 단위 `--space-*`만 씁니다.
- **누르는 영역:** 최소 44px(`--control-height`)입니다.

### 큰글씨 모드

모든 크기는 `rem`이므로 `html.large-text`의 `font-size: 130%` 하나로 함께 커집니다. 카드는 1단으로 바뀌고, 요약 글은 잘리지 않습니다. 크기를 `px`로 지정하면 큰글씨 모드에서 커지지 않으니 쓰지 않습니다.

## 4. 컴포넌트

| 이름 | 용도 | 변형과 상태 |
| :--- | :--- | :--- |
| `button` | 동작 실행 | `--primary`, `--secondary`, `--block` / hover, active, focus, `aria-pressed` |
| `select` | 지역 선택 | hover, focus, disabled |
| `check` | 켜고 끄는 선택 | 체크 여부 |
| `search` | 키워드 검색 | 입력하면 지우기 버튼 표시, `Esc`로 지우기 |
| `filter-chip` | 목록 좁히기 | 선택, 0건이면 비활성 / 건수 표시 |
| `filters` | 필터 접기 | 휴대폰에서는 접힘, 넓은 화면에서는 항상 펼침 |
| `card` | 복지 한 건 | hover, active, focus / 제목 버튼이 카드 전체를 덮음 |
| `chip` | 표시 전용 라벨 | `--local`, `--national`, `--quiet`, `--review` |
| `state-panel` | 빈 결과와 오류 | 기본, `--error` |
| `dialog` | 상세 안내 | 휴대폰은 아래에서 올라옴, 넓은 화면은 가운데 |
| `doc-item` | 서류 체크 | 체크하면 강조, 진행 상황 표시 |

## 5. 화면 상태

```text
[불러오는 중] --성공--> [목록] --조건에 맞는 항목 없음--> [빈 결과] --조건 지우기--> [목록]
              --실패--> [오류] --다시 시도--> [불러오는 중]
```

| 상태 | 사용자가 보는 것 | 규칙 |
| :--- | :--- | :--- |
| 불러오는 중 | 뼈대 카드 | 200ms 뒤에만 보임 (빠를 때 깜빡임 방지) |
| 목록 | 카드 30개씩 | `더 보기`를 누르면 새 카드 첫 항목으로 초점 이동 |
| 빈 결과 | 이유와 다음 행동 | 막다른 길을 만들지 않음 |
| 지역 미선택 | 전국 공통 복지 | 임의의 지역을 미리 고르지 않음 |
| 오류 | 다시 시도, 복지로, 129 | 10초 안에 응답이 없으면 오류로 전환 |

## 6. 상호작용 규칙

| 동작 | 규칙 | 피드백 |
| :--- | :--- | :--- |
| 지역 선택 | 저장 버튼 없이 바로 반영 | 제목과 건수가 바뀌고 화면 낭독기에 알림 |
| 지역 기억 | 사용자가 켤 때만 저장, 끄면 즉시 삭제 | 체크 상태 |
| 검색 | 입력하는 대로 반영, 띄어쓰기 무시 | 건수 변경 |
| 상세 닫기 | `Esc`, 닫기 버튼, 바깥 누르기 | 누른 카드로 초점 복귀 |
| 서류 체크 | 이번 방문에서만 유지, 저장하지 않음 | 진행 상황, 완료 시 다음 행동 안내 |

- 되돌릴 수 있는 동작에는 확인 창을 쓰지 않습니다.
- 애니메이션은 200ms 이하로 하고, 동작을 막지 않습니다.
- `prefers-reduced-motion`과 Windows 고대비 모드를 지원합니다.

## 7. 보안 규칙

- 데이터 글자는 `textContent`로만 넣습니다. `innerHTML`을 쓰지 않습니다.
- 링크는 `http`와 `https`만 허용합니다.
- 인라인 스크립트와 스타일을 쓰지 않습니다. 콘텐츠 보안 정책(CSP)이 막습니다.

## 8. 고칠 때 지키는 것

1. 값을 바꿀 때는 토큰을 고칩니다. 컴포넌트에 값을 직접 쓰지 않습니다.
2. 새 컴포넌트는 기본, hover, focus, 비활성, 오류 상태를 함께 정합니다.
3. 변형은 5개를 넘기지 않습니다. 넘으면 컴포넌트를 나눕니다.
4. 이름은 내용이 아니라 구조로 짓습니다. (`card`는 되고, `policy-card`는 안 됩니다.)

`backend/tests/test_public_page.py`가 이 규칙 중 일부를 자동으로 검사합니다. 색 원시 값, 14px 미만 글자, `innerHTML`, 외부 리소스, 인라인 코드, 금지 문구를 막습니다.
